## 3. The generated-assets decision — ask me before deciding

`audio/` is ~35 MB, of which ~33 MB is 22 music WAV stems. **Every asset in this
project is generated by scripts in `tools/`** (`gen_textures.py`, `gen_audio.py`,
`gen_music.py`), so they are reproducible from source.

Lay out the trade-off and let me pick:
- **Commit them** — repo is ~90 MB, but a clone is immediately runnable and
  GitHub is fine with it (the soft warning is at 50 MB *per file*, hard limit
  100 MB per file; no individual file here is over ~2 MB).
- **Git LFS** for `audio/*.wav` — smaller clone, but adds an LFS dependency and
  a step for anyone cloning.
- **Gitignore them** and require running the generators after clone — smallest
  repo, but a fresh clone won't run until you do. If you propose this, also add
  a CI step or a `make assets` equivalent so it isn't a trap.

My default preference is **commit them** unless you find a real problem, because
this is a solo project and a clone that just works is worth 90 MB.
